宝塔静态托管

不需要后端，把以下文件放到站点目录即可。

1

上传目录文件

把本站点文件（index.html、admin.html、assets/）放到站点根目录，开启 HTTPS。

站点根目录 /
2

上传应用包

每个版本一个 ZIP，根目录包含 config.json 与 main/，放在以 appId 命名的目录下。

packages/{appId}/{versionCode}.zip
3

生成并上传 apps.json

在发布控制台拖入 ZIP，自动读取版本并校验 SHA-256，导出 apps.json 后上传。

/apps.json
4

开启访问鉴权

宝塔面板 → 网站 → 设置 → 密码访问，开启并设置账号密码，整站（含 apps.json 和 packages/）都会要求凭据。

宝塔「密码访问」/ Nginx Basic Auth
5

宿主填写应用源

在 App 设置中填写目录地址和鉴权用户名密码；宿主请求会自动携带凭据，且只允许同域下载。

https://你的域名/apps.json
